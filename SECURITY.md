# Security policy

The project-wide FireViewer security policy is maintained at:

https://github.com/fireviewer/.github/blob/main/SECURITY.md

Please report suspected vulnerabilities through GitHub private vulnerability
reporting when available, or privately to:

**unicornwhodev@gmail.com**

Do not include credentials, tokens, private incident evidence, personal data or
security-sensitive details in a public issue.

Repository-specific implementation details do not override the project-wide
security, provenance and evidence-integrity policy.

FireViewer is not an emergency service. For an active emergency, contact the
relevant authorities and emergency services.
