# FireViewer AI Worker

This repository contains a FireViewer software component for private
AI-assisted evidence analysis. Its public presence is limited to this concise
description and the applicable licence and security information.

It does not publish private incident evidence, model weights, checkpoints,
secrets, or operational claims.

> FireViewer AI output is a proposal, not an emergency alert, an official
> wildfire record, a command decision, or a certified forecast.

For the public project overview and collaboration contact, see
[FireViewer](https://github.com/fireviewer/Fireviewer_doc).
